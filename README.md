# Prueba Design Engineer · Bia | Olibia

Dos tareas en React con un design system compartido.

| Tarea | Ruta | Código |
|---|---|---|
| 01 · Uplift radical de Olibia (dashboard comercial) | `/` | [`dashboard-prueba/src/olibia`](dashboard-prueba/src/olibia) |
| 02 · Experiencia para Bia (factura de energía) | `/bia` | [`dashboard-prueba/src/bia`](dashboard-prueba/src/bia) |
| Design system | `/#componentes` | [`dashboard-prueba/src/ui`](dashboard-prueba/src/ui) |

## Ejecutar

Requiere Node.js 20 o superior.

```sh
cd dashboard-prueba
npm ci
npm run build
npm start
```

Abre http://localhost:3000 (Olibia) y http://localhost:3000/bia (Bia).
